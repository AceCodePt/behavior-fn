Command Dispatcher No Prefix

What is this?

This example demonstrates BehaviorFN's Command Dispatcher - a custom command protocol that extends beyond the native Invoker Commands API.

Key Features:

  • ✅ No -- prefix required (use command="show" not command="--show")
  • ✅ Automatic commandfor + command wiring
  • ✅ Multiple targets and multiple commands support
  • ✅ Defers to native API when available

Example 1: Basic Commands

Simple show, hide, and toggle commands.

🎉 Modal Dialog

This modal was opened via the command dispatcher!

 
<button commandfor="modal" command="show">Show Modal</button>
<button commandfor="modal" command="toggle">Toggle Modal</button>

<dialog is="behavioral-reveal" id="modal" behavior="reveal">
  <h3>Modal Dialog</h3>
  <button commandfor="modal" command="hide">Close</button>
</dialog>

Example 2: Popover (Native API)

Using the popover attribute with reveal behavior.

💡 Tooltip Content

Example 4: Compatibility Mode

The dispatcher accepts both prefixed (--show) and non-prefixed (show) commands.

Compatibility Mode

Both buttons work! The -- prefix is normalized internally.

 
<!-- Both work -->
<button commandfor="modal" command="--toggle">Prefixed</button>
<button commandfor="modal" command="toggle">Non-prefixed</button>

How It Works

  1. Import command-dispatcher: Automatically wires up click handlers for [commandfor] elements
  2. Click a trigger: Dispatcher finds target(s) by ID
  3. Dispatch command: Fires CommandEvent on target element(s)
  4. Behavior handles it: The reveal behavior's onCommand handler executes

No JavaScript required! Just add commandfor and command attributes.
